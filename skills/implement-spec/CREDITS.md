# Credits

The worker report, exclusive integration ownership, recovery responsibilities, and verification tied to a commit adapt Lauren Tan's pstack [orchestration playbook](https://github.com/cursor/plugins/blob/99b609a72323b70204eab407c622f436e858e112/pstack/skills/poteto-mode/playbooks/orchestrate.md). This version keeps the existing ticket graph and worktree workflow without adding pstack's orchestration store.
